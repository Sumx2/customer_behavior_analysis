# 🛍️ Customer Shopping Behavior Analysis

A complete end-to-end data analytics project that analyzes customer shopping behavior using Python, SQL, and Power BI. The project focuses on understanding customer purchasing patterns, identifying business opportunities, and presenting actionable insights through an interactive dashboard.

---

## 📌 Project Overview

This project analyzes transactional data from **3,900 customer purchases** to uncover insights into customer demographics, spending habits, product preferences, subscription behavior, and purchasing trends. The objective is to help businesses make data-driven decisions that improve customer engagement, increase revenue, and optimize marketing strategies. :contentReference[oaicite:0]{index=0}

---

## 📂 Dataset

The dataset contains customer shopping transactions with **3,900 records** and **18 features**.

### Key Features
- Customer Demographics (Age, Gender, Location)
- Purchase Details (Product, Category, Amount)
- Shopping Behavior
- Subscription Status
- Discounts & Promo Codes
- Shipping Type
- Customer Reviews
- Purchase Frequency

## 📈 Project Workflow

### 1. Data Loading
- Imported dataset using Pandas
- Performed initial exploration
- Checked data types and summary statistics

### 2. Data Cleaning
- Handled missing values
- Renamed columns for consistency
- Removed redundant columns
- Performed data validation

### 3. Feature Engineering
- Created customer age groups
- Generated purchase frequency features
- Prepared dataset for SQL analysis

### 4. SQL Analysis
Performed business-focused SQL queries including:

- Revenue by Gender
- High Spending Discount Users
- Top Rated Products
- Shipping Type Comparison
- Subscribers vs Non-Subscribers
- Customer Segmentation
- Revenue by Age Group
- Repeat Buyer Analysis
- Top Products by Category
